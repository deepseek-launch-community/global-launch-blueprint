# Contribution Guide (贡献指南)

**Three Paths:**
1. **Structured Cases**: Submit to `case-library/` (review required)
2. **Experimental Cases**: Submit to `experimental-cases/by-contributor/` (pain report required)
3. **Protocol Feedback**: Discuss in `#protocol-pain-points`

**开始参与：**
1. 阅读 `experimental-cases/README.md`
2. 创建你的贡献者目录
3. 尝试转换一个案例
4. 提交并包含困惑报告
