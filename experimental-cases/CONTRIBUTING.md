# Contribution Guide

## Project Positioning
SRCP/LLRK is a technical standards project defining structured, governance-grade provenance protocols for AI decision processes.

## Three Contribution Paths

### Path A: Submit Structured Cases
- **For**: Those who understand SRCP Schema and can produce compliant JSON
- **Location**: `case-library/` (requires review)
- **Requirement**: Must pass `schemas/validate.py` validation

### Path B: Submit Experimental Conversions (Recommended Starting Point)
- **For**: Have dialogue/reasoning cases but unsure how to convert to SRCP format
- **Location**: `experimental-cases/by-contributor/your-username/`
- **Requirement**: **Must include pain report** (using TEMPLATE.md)

### Path C: Provide Protocol Feedback
- **For**: Discovered issues in SRCP design
- **Location**: GitHub Discussions `#protocol-pain-points`
- **Requirement**: Specific scenario + concrete improvement suggestion

## Support & Limitations

| We **Can** Provide | We **Cannot** Provide |
|-------------------|----------------------|
| Clear protocol Schema & documentation | One-on-one technical support |
| Basic validation tools & templates | Immediate question answering |
| Monthly review of pain reports | Guarantee all cases will be accepted |
| Serious review of protocol suggestions | Acceptance of unstructured cases |

## Workflow
1. **Fork** this repository
2. **Choose** appropriate contribution path
3. **Submit** content in corresponding directory
4. **Create** Pull Request with clear description
5. **Wait** for review by core team

## Getting Help
1. **Self-help first**: Read `docs/conversion-starter.md`
2. **Community help**: Ask in `#experimental-case-help` Discussions
3. **Review examples**: Check existing cases for reference
