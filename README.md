## 🔥 DeepSeek-V4 — Key Highlights

The V4 preview represents a major leap, pioneering a **1-million-token context window as standard** across all services. Two model variants are available:

| Model | Positioning | Highlights |
| :--- | :--- | :--- |
| **DeepSeek-V4-Pro** | Performance flagship | Agent capability comparable to top closed-source models; rich world knowledge; state-of-the-art reasoning. |
| **DeepSeek-V4-Flash** | Fast & economical | Competitive reasoning at lower cost; strong on simple agent tasks. |

**Technical innovations include:**
*   **Novel Attention Mechanism**: Token-dimension compression with **DeepSeek Sparse Attention (DSA)** for exceptional long-context efficiency.
*   **Agentic Optimization**: Fine-tuned for tools like Claude Code, OpenClaw, and CodeBuddy, showing strong gains in agentic coding.
*   **Dual Modes**: Both models support non-thinking and **thinking mode** (with adjustable `reasoning_effort`).
